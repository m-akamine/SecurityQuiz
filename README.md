# セキュリティ〇×クイズ

Windows 11向けの、Tkinter製セキュリティクイズアプリです。問題は
[`261113セキュリティクイズ問題.json`](./261113セキュリティクイズ問題.json)
から読み込みます。顔位置検出にはOpenCVの顔検出器、ローカル読み上げには
Windowsの `System.Speech` を使用します。

## 起動準備

1. Windows 11にPython 3.10以降をインストールします。インストール時に
   PythonをPATHへ追加してください。
2. PowerShellをこのフォルダーで開き、次を実行します。

   ```powershell
   $python = Get-ChildItem "$env:LOCALAPPDATA\Programs\Python\Python*\python.exe" |
       Select-Object -First 1 -ExpandProperty FullName
   & $python -m pip install -r requirements.txt
   ```

3. Windowsに日本語の音声がインストールされていることを確認します。
   アプリは `ja-JP` のWindows音声（例: Microsoft Haruka Desktop）を利用し、
   見つからない場合はゲームを開始できません。
4. カメラを接続し、Windowsの設定でデスクトップアプリのカメラ使用を許可します。
5. [`start_quiz.bat`](./start_quiz.bat) をダブルクリックするか、次を実行します。

   ```powershell
   py -3 app.py
   ```

既定ではカメラ番号0を使用します。別のカメラを使う場合は
`py -3 app.py --camera-index 1` のように番号を指定してください。

## Windows実行ファイルの作成・配布

Pythonをインストール済みのビルド用Windows PCで、次を一度実行してから
[`build_windows.bat`](./build_windows.bat) をダブルクリックします。

```powershell
py -3 -m pip install -r requirements-build.txt
```

作成された `dist\SecurityQuiz_Adjusted.exe` を配布します。問題データ、背景画像と
効果音、Python・アプリ依存ライブラリは実行ファイルに含まれるため、配布先にPythonは不要です。
配布先PCではカメラの使用を許可し、日本語音声（`ja-JP`）を利用できるようにしてください。
Windows標準のPowerShellも読み上げに使用します。Windows向けの実行ファイルはWindows上で
ビルドしてください。

Pythonで実行・ビルドする場合は、タイトルバーを除いた `BackgroundImage_Clean.png` を
`app.py` と同じフォルダーに置いてください。背景画像は実行ファイルに含まれます。
元の `BackgroundImage.jpg` はそのまま残しています。

各画面に切り替わった時に、`sound` フォルダー内の対応するMP3効果音を再生します。
「第○問」画面では共通音の後に問題番号の音声を続けて再生し、回答中のタイマー音は
回答画面が終わると停止します。

## 遊び方

- 起動時は全画面表示です。`F11` でウィンドウ表示と切り替え、`Alt+F4` で終了できます。
- ホーム画面で「カメラ確認」を押すと、鏡像のライブ映像と検出した顔の枠を
  確認できます。カメラ動作の事前確認に利用してください。`Esc` で戻ります。
- ホーム画面の「カメラ」一覧からWindowsが認識しているカメラを選べます。
  USBカメラを接続し直した場合は「カメラ一覧を更新」を押してください。
  カメラ切替後は映像が準備できてからゲームを開始します。
- ホーム画面で顔を1〜5人検出すると、自動で10秒カウントダウン後に出題が始まります。
  顔が一時的に検出できなくても2秒間は再検出を待ちます。2秒以内に戻らない場合は
  ホーム画面に戻り、顔を再検出すると10秒カウントダウンをやり直します。
- スタッフは「ゲーム開始」または`Space`キーで参加者待ちに入り、カウントダウンを
  待つこともできます。`Space` キーで参加者待ちを中止できます。
- 顔を検出できない場合は、ホーム画面・参加者待ち・カウントダウン中に `F7` を押すと
  手動で開始できます。カメラと日本語音声は正常に使用できる必要があります。
  顔が検出できない状態で手動開始した場合は、そのプレイの自動正誤判定は行いません。
- 各問題の前に「第1問」などを4秒表示します。問題文の読み上げの最後には
  「まるかばつか」を付けます。
- 画面左の〇、右の×へ移動して回答します。
- 回答が終わると、正解側の領域を薄い色で点滅させ、解説までの残り時間をゲージで
  表示します。正解者には「正解！」、不正解者には「不正解」と表示してから解説に進みます。
  ゲーム中の検出人数が開始時と異なっても進行を止めません。回答終了時に人数が
  揃っていない場合は正誤の個別表示と正誤の効果音を出さず、スタッフが確認します。
- 回答終了時に全員の顔を確認できた場合は、解説を5秒以上表示し読み上げが終わると、
  全員正解なら次の問題へ、不正解者がいれば「残念」画面へ自動で進みます。
  顔の人数を確認できなかった場合は解説画面でスタッフの操作を待ちます。
  `F8` で次の問題へ進み、最終問題では全問正解の画面へ進みます。
  `F9` で不正解として「残念」画面へ進みます。読み上げ中でも操作でき、
  操作時に読み上げを停止します。自動判定済みの場合もスタッフ操作で切り替えられます。
- 全問正解の場合は結果画面を10秒、不正解者がいた場合は「残念」画面を5秒表示してホームに戻ります。
  エラーや中止理由もポップアップではなく画面内に表示します。
- 途中参加はできません。
- スタッフは `Ctrl+Shift+Q` または `F12` から確認後に中止できます。
- セットはプレイ開始ごとに1→2→3→4→5→1と進みます。アプリを再起動すると
  セット1に戻ります。
- 表示フォントはPCにインストール済みのNoto Sans JP、BIZ UDPゴシック、
  游ゴシック UI、メイリオ UIの順に選択します。フォントは実行ファイルに含まれません。
  WindowsやTkでフォント名が別表記の場合は、次の候補を使うことがあります。

## プライバシーと制約

- 映像は顔位置検出と円形ライブ表示にだけ使用し、ファイルへ保存せず、
  ネットワークや外部サービスへ送信しません。
- OpenCVが顔検出モデルを読み込めるよう、モデルファイルのみをWindowsの一時
  フォルダーへ一時コピーし、カメラ終了時に削除します。映像・顔画像は書き込みません。
- 顔認証・個人特定は行いません。追跡IDはゲーム中の位置対応だけに使います。
- ゲーム中は顔の検出人数が不足・超過しても中断しません。回答終了時に人数が
  揃わなかった場合はスタッフが正誤を判断します。
  個人の区別は保証されず、正解発表中の個別表示が入れ替わることがあります。
- 顔を検出してゲームを開始した後は、登録した参加者の顔の周辺のみを検出し、
  離れた通行人の顔は探しません。顔なしで手動開始した場合は登録・自動判定しません。
  顔の移動に合わせて検出範囲も移動します。参加者のすぐ近くを通る人は検出範囲に入る
  可能性があり、急な移動では参加者を見失うこともあります。会場では参加者と通行人の
  距離を確保し、実際の移動速度で事前に確認してください。
- 顔検出はOpenCVの正面顔・横顔Haar分類器を使い、左右向きの横顔も検出します。
  ゲーム中に参加者周辺で顔が見つからない場合は、その範囲のコントラストを補正して
  再検出し、直前の顔に近い位置と大きさの候補だけを使用します。
  正面顔検出の感度も調整していますが、照明、距離、顔の角度によって検出性能が
  変わるため、会場のカメラ位置で事前テストしてください。横顔検出は大きく横を
  向いた顔に有効で、わずかな顔の傾きや遮蔽で必ず検出できるわけではありません。
- 現在のWindows環境では「HD Webcam」が検出されましたが、仕様書指定の
  Logicool C920nでの実機テストは未実施です。利用環境でC920nを接続し、
  1〜5人の検出、左右判定、退場動作を確認してください。

## テスト

標準ライブラリの `unittest` で問題データ検証・左右判定・位置追跡を確認します。

```powershell
$python = Get-ChildItem "$env:LOCALAPPDATA\Programs\Python\Python*\python.exe" |
    Select-Object -First 1 -ExpandProperty FullName
& $python -m unittest discover -s tests -v
```
